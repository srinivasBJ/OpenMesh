# OpenMesh Documentation Archive

This directory (`docs/archive/`) stores historical, superseded, and point-in-time audit documents from earlier phases of OpenMesh.

> **Important**:
> Documents in this directory are preserved for historical provenance, audit trails, and context. They are **not** active product documentation and may describe superseded commands, early release notes, or completed audits.
